# Sound controls validation — 2026-10-08

Hardware-free CTest checks exercise silence, settled single-note pitch, bounded processor output, effects producing finite output, and a smoothed mute transition. They passed. The Dear ImGui application opened in a short GUI smoke run and remained running until the five-second timeout. Panels expose separate controls, route state, meters, and diagnostics; window layout and spacing now respond to viewport size and content scale.

On 2026-10-09 the user tested a connected guitar/interface and reported that the effect sounded fuzzy while full bypass was clean. A sine voice sounded synthetic; adding filtered dry pickup signal improved the tone but the user correctly noted it was not shifting the guitar waveform. In-house granular pitch shifting sounded distorted. The user preferred the Rubber Band R3 waveform shift when the comparison files were tone-filtered and level-matched to the app's -6 dB default output. The live build now uses this full-waveform shift at 100% wet, without a dry or synthesized voice blend, but the user has not yet listened to it live. Sustained-note control changes, audible bypass/mute clicks, clipping with real guitar input, and visual inspection of resized and high-DPI UI still need review. The application uses a final -1 dBFS clamp; that numerical check does not substitute for safe listening validation.
